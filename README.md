# Pandit Kartick Kumar — Digital Chowk

An immersive tribute website to the sitar maestro **Pandit Kartick Kumar** (b. 11 November 1936),
a fourth-generation sitarist and senior-most disciple of Pandit Ravi Shankar.

## Structure
- `index.html` — the page
- `css/styles.css` — styling
- `js/script.js` — hero sitar, the Journey timeline, and the gallery pages
- `assets/` — photographs and archive images

## Run locally
Open `index.html` in any browser (keep internet on first load — fonts come from Google Fonts).

## Deploy
Static site — deploys on Vercel / Netlify / GitHub Pages with no build step.
